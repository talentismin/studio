隨身書房 Pocket Bookroom User Guide

使用說明

隨身書房是一款純本機的電子書閱讀器（TXT / EPUB / MOBI）：匯入你自己的書，即可離線閱讀、聽朗讀、做書籤。所有書本與進度都留在你的裝置上，不需註冊帳號、不上傳雲端。

第一次使用

  1. 打開 App，會看到「書齋」（你的書架），一開始是空的。
  2. 點右上角的 ＋ 匯入一本電子書（見下方）。
  3. 點書封進入閱讀畫面，即可開始看。

整個流程都在本機完成，不需連網、不需登入。

匯入書本

支援格式：.txt、.epub、.mobi。兩種匯入方式：

方法 A — 從手機檔案匯入

  1. 在書齋點右上角 ＋。
  2. iOS 文件選擇器跳出後，從「iCloud 雲碟 / 檔案 / 其他 App」選擇電子書檔。
  3. 也可在其他 App 用「分享 / 開啟方式」選擇隨身書房。

方法 B — 用電腦透過 Wi-Fi 傳（適合一次傳多本）

見下方「Wi-Fi 傳書」。用電腦瀏覽器把檔案丟進手機，不用線、不用其他 App。

提醒：請匯入你合法擁有的電子書檔案。App 不提供任何書本內容，也不會審查匯入的檔案，內容合法性由使用者自行負責。

書齋（書架）

  • 繼續閱讀：書架上方顯示最近在看、尚未讀完的書，一鍵接續。
  • 閱讀進度：每本書封顯示已讀百分比。
  • 排序：右上角切換「最近閱讀 / 書名 / 匯入時間」。
  • 搜尋書本：用書名快速找書。
  • 刪除書本：左滑書本刪除（會一併移除進度與書籤）。（完整版功能）

閱讀與翻頁

進入閱讀畫面後，整頁就是內文，分成三個觸控區：

點擊位置動作
畫面左側上一頁（預設）
畫面中央叫出 / 收起閱讀工具列
畫面右側下一頁（預設）
  • 也可左右滑動翻頁（可在手勢設定關閉）。
  • 左右翻頁方向可反轉（方便左手單手持機）。
  • 畫面底部細進度條顯示目前百分比與預估剩餘時間。

閱讀工具列

在閱讀畫面點中央叫出工具列，可使用：

  • 進度條：拖曳跳到書中任一位置。
  • 字級 −／＋、行距 −／＋。
  • 字型：系統、襯線、圓體、楷體、宋體。
  • 主題：快速切換閱讀紙色。
  • 目錄、朗讀、加書籤、書籤、搜尋（書內全文搜尋）。

字級、字型與主題

  • 閱讀紙色主題：預設、夜間、護眼、羊皮紙。
  • 明暗模式：跟隨系統 / 強制淺色 / 強制深色（只影響 App 介面，閱讀紙色由主題決定）。
  • 夜間自動切換閱讀主題：系統切深色時閱讀紙色自動換成「夜間」，切回淺色再換回日間主題。

工具列可即時調整；設定 內可設預設值。

朗讀（語音）

在工具列點 朗讀 開啟朗讀面板，由 iOS 內建語音合成（TTS）唸給你聽。

播放控制

  • 播放 / 暫停 / 停止；上一段 / 下一段。
  • 正在唸的句子會在內文中 highlight 並自動捲動跟上。
  • 顯示目前段落 / 總段數。
  • 語速、語調可即時調整（也可在設定設預設值）。
  • 睡眠定時器：設定幾分鐘後自動暫停，適合睡前聽。

背景與鎖屏播放

  • 切到背景或鎖屏時可繼續播放。
  • 可用鎖屏 / 控制中心的播放控制鈕操作。

選擇語音與音質

面板可挑中文語音。預設只有「普通音質」語音；想要更自然的聲音：

iOS 設定 → 輔助使用 → 朗讀內容 → 語音 → 中文，下載「進階」或「Premium」版本，再回 App 選用，音質會明顯提升。

目錄、書籤與搜尋

  • 目錄：自動辨識章節標題（如「第一章」「序章」「楔子」），點章節即可跳轉。若書中無可辨識章節標題會提示「沒有偵測到章節」。
  • 書籤：點「加書籤」標記目前位置；之後從「書籤」清單一鍵跳回。
  • 書內搜尋：工具列點「搜尋」，輸入關鍵字做全文搜尋，點結果直接跳到該位置。

自動翻頁

在 設定 → 自動翻頁 開啟後，App 依設定的間隔秒數自動往下翻頁，免手動，秒數可自行加減。

手勢設定

在 設定 → 功能 → 手勢：

  • 反轉翻頁方向：把左右點擊區對調（左手持機更順手）。
  • 允許左右滑動翻頁：可關閉滑動翻頁，只用點擊。

Wi-Fi 傳書

把電腦裡的電子書，透過同一個 Wi-Fi 直接傳進手機，不需線、不經雲端。

  1. 手機與電腦連到同一個 Wi-Fi 網路。
  2. App 內 設定 → 功能 → Wi-Fi 傳書，打開「啟動 Wi-Fi 傳書」。
  3. 畫面顯示一個網址與一組 6 位數配對碼。
  4. 在電腦瀏覽器打開該網址，輸入配對碼，即可上傳 .txt / .epub / .mobi。
  5. 上傳完成的書會自動出現在書架。
注意：僅同網段裝置可連線；配對碼輸入錯誤 3 次會鎖 30 秒。傳輸只在你開啟期間有效，關閉即停止，全程不經任何雲端。

電腦閱讀模式

反過來：在電腦瀏覽器閱讀手機裡已有的書，大螢幕看更舒服。

  1. 手機與電腦連同一個 Wi-Fi。
  2. 設定 → 功能 → 電腦閱讀模式，點「啟動電腦閱讀模式」。
  3. 在電腦瀏覽器打開顯示的網址，輸入 6 位數配對碼。
  4. 即可在電腦上翻閱手機內的書。
注意：使用期間請讓 App 保持在前景、不要鎖屏；鎖屏或切到背景約 30 秒後，iOS 會暫停伺服器、連線中斷。另外 30 分鐘沒有閱讀進度更新會自動停止。第一個輸入正確配對碼的瀏覽器取得連線，其他要再配對。

簡繁轉換

在 設定 → 中文字形 → 簡繁轉換 可選：不轉換 / 簡 → 繁 / 繁 → 簡。轉換只影響閱讀內文與朗讀文字，不會改動原始檔案。

常見問題

朗讀拔耳機後就停了，按播放只播一下？

拔耳機時系統會停止播放。回到 App 朗讀面板（或鎖屏控制）再按一次播放即可從目前位置繼續。

朗讀聲音不夠自然？

到 iOS 設定 → 輔助使用 → 朗讀內容 → 語音 → 中文，下載「進階／Premium」語音，再回 App 選用。

打開目錄顯示「沒有偵測到章節」？

表示這本書內文沒有可辨識的章節標題（例如「第一章」）。仍可用進度條或書籤定位。

電腦連不到 Wi-Fi 傳書 / 電腦閱讀模式？

確認手機與電腦在同一個 Wi-Fi 網段、App 在前景未鎖屏、配對碼正確（錯 3 次鎖 30 秒）。部分公司 / 公共 Wi-Fi 會隔離裝置（AP isolation），這種網路無法互連。

匯入失敗或顯示無法解碼？

多半是 .txt 編碼問題。可在電腦上把檔案另存為 UTF-8 後再匯入。

換手機後書還在嗎？

資料存在本機，換機需重新匯入。建議用 Wi-Fi 傳書把書留一份在電腦備份。

我的書和閱讀紀錄會上傳嗎？

不會。本 App 不營運伺服器、不蒐集個資，所有資料僅存於裝置本機。詳見 隱私權政策。
